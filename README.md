# 第一性原理：从前提、证据到可纠错的判断

饶秋的第一性原理学习手册，面向希望把这一方法用于真实问题的读者。

这份材料关心的是：一个判断依赖什么前提？哪些限制确实绕不开，哪些只是习惯？什么证据出现时，我们应该改变主意？

## 阅读与下载

- [查看 PDF](first-principles.pdf)：101 页，适合连续阅读与打印。
- [下载 HTML](https://github.com/raoqiu29-bot/first-principles/raw/refs/heads/main/first-principles.html)：下载后用浏览器打开；字体已嵌入，阅读正文不依赖联网，资料外链需要联网。

手册仅提供 HTML 和 PDF 两种格式。初次阅读可先看导读，再跟随“交付出了错，先加审批吗”的连续案例，用自己的低风险问题练习；思想史和资料来源可按需回查。

## 内容与构思

材料从李善友《第一性原理》的学习整理出发，加入哲学、科学方法与系统思维的比较，再把方法放回工作、学习、自媒体和生活问题。

内容包括不同学科中“第一性原理”的含义，中西思想资源，边界、反馈与涌现，判断与检验的方法，连续教学案例，以及可打印工作表。

材料含有 AI 协作整理。思想来源、综合框架和未解决的问题分别说明；教学案例中的数字与结果按原文标记理解，不能当作饶秋或某家公司的实际记录。它是一份学习与方法整理，不能替代原书，也不代表相关作者或机构认可本项目。
